# why long-running agents need checkpoints

Long-running agents can crash or get interrupted at any time, but checkpoints allow them to resume from the last saved state instead of starting over completely, preventing loss of all previous work. Checkpoints improve resource management by saving incremental progress, which reduces computational waste and enables better memory and processing power allocation through manageable segments with defined save points. Over extended periods, failures, updates, and maintenance are inevitable, making checkpoints essential for reliable operation since they provide recovery points that minimize disruption. By regularly preserving progress, checkpoints turn potential catastrophic failures into minor setbacks, dramatically improving the dependability of long-running agents.
